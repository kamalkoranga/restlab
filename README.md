# 🚀 RestLab – Lightweight API Testing Tool

RestLab is a simple, intuitive API testing tool built as a hackathon project, inspired by tools like Postman. Designed for speed and simplicity, RestLab lets developers test RESTful APIs with ease, without bloated features or unnecessary complexity.

## ✨ Features
- 🧪 Send HTTP requests (GET, POST, PUT, DELETE, PATCH)
- 📂 Save & manage collections of requests
- ⚡ Fast and responsive interface
- 🧾 View formatted response (JSON / Text)
- ⌨️ Add environment variables
- 🌐 CORS-friendly (if web-based)
- 📁 Import/export requests as JSON
